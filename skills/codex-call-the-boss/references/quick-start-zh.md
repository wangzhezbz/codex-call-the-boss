# 第一次使用 Call the Boss

让 Codex 在工作完成后打电话简短汇报。你可以在电话里提问、交代下一步工作，指令会回到原来的 Codex 任务执行。

## 1. 准备设备

- 一台带有 Phone.app 的 Mac，已登录 Codex 桌面端。
- 一部与 Mac 使用同一 Apple 账户、已开启“在其他设备上通话”的 iPhone，手机线路可以正常拨出电话。
- 一个能接听电话的号码，不能与拨出线路相同。配置时，Codex 会直接问你：“请把用于接收汇报电话的手机号码发给我。”不要把号码放进公开文档或分享包。
- Mac 和 Codex 在使用期间保持运行，不要休眠。

还需要 Python 3.11+、BlackHole 2ch/16ch 和辅助功能权限。没有安装也不用猜着配置，先让 Codex 检查，再按提示补齐。Phone.app 最近通话中需要有接听号码和可用的“呼叫”按钮；若没有，Codex 会提示你手动建立这条记录。

目前支持 macOS + iPhone，不支持 Windows、Linux 或没有 iPhone 电话接力的环境。

## 2. 让 Codex 引导安装

解压下载的 Skill，将其中的 `codex-call-the-boss` 文件夹交给 Codex，发送：

> 我是第一次使用 Call the Boss。请读取这个文件夹里的 SKILL.md，先检查我的设备和环境，再引导我完成安装、电话接力、接听号码、音频和权限配置。不要假设我已有任何电话配置。安装组件、修改权限或启用收费服务前先征求我的同意。配置完成后，仅为当前任务启用电话汇报，不要直接拨号，等我确认后再试打。

安装、配置和启用是不同步骤。下载或解压不会自动拨号；如果你要求先不拨号，本次配置结束也不应触发电话。启用后，之后的任务完成会自动汇报。

如果 Codex 无法读取附件，告诉它解压后的文件夹完整路径，让它从其中的 `SKILL.md` 开始。已有同名安装时，先检查，不直接覆盖。不要从分享者那里复制号码、密钥、账户登录或通话记录。

## 3. 检查配置并试打一通

配音配置前，Codex 会先问你选择系统语音还是豆包语音，不会直接替你决定。

- 选系统语音：试听并选择 Mac 已安装的声音，无需申请配音 API Key。
- 选豆包：先打开[火山引擎控制台](https://console.volcengine.com/ark/region:cn-beijing/overview)登录，再到[模型开通页面](https://console.volcengine.com/ark/region:cn-beijing/openManagement?advancedActiveKey=model&tab=TTS)选择模型。普通配音推荐语音合成 2.0；已有获授权复刻音色时可选声音复刻 2.0。
- 也可以选“自行选择语音模型”，把模型名称或 ID 告诉 Codex，先检查兼容性再决定开通。
- 在[音色库](https://console.volcengine.com/speech/new/voices?projectName=default)按模型筛选、试听并复制音色 ID。标准 2.0 可先试听甜美小源、Vivi、云舟，最后由你选择。
- 在 [API Key 管理](https://console.volcengine.com/speech/new/setting/apikeys?projectName=default)创建语音服务密钥，通过 Codex 引导的私有终端隐藏输入。不要把密钥发到聊天里。
- 确认费用后再进行合成试听。具体音色 ID 与兼容性说明见[豆包配置](doubao.md)。

配置完成后，让 Codex 检查运行状态。确认可以测试后，说：

> 打给我测试一次。

拨号前，Codex 会先告诉你电话里怎么使用：

1. **接听并说“喂”**，然后听这次任务的简短汇报。
2. **正常交流**。你可以问“具体完成了哪些？”“还有什么问题？”“为什么这样做？”“两种方案有什么区别？”，也可以要求“再解释一下”或“说简单一点”。不必一接电话就下任务；提问、讨论方案与要求实际修改是不同的。
3. **准备好后下达任务**，请说：

   > 下一步的任务是：XXXXX。

   例如：“下一步的任务是：检查首页的所有链接，修复打不开的链接，完成后告诉我改了哪些。”

   尽量说明要做什么、范围和完成标准。这个句式用于表达清楚，不是额外授权口令。
4. **听取接收回执**。确认指令送达后可以挂断，等待任务完成后的下一次电话。若提示“执行状态暂未确认”，请回原任务查看，不代表已经开始执行。

每通电话最多提交一条执行指令。提交后还要修改或取消，请回到原来的 Codex 任务操作。如果只是问问题、不下达任务，交流结束后直接挂断即可。

试打时，除了确认声音和问答正常，还要回到原任务检查指令是否收到并执行；任务完成后，再确认下一次电话汇报。

每次只拨打一次。未接到或失败时不会自动重拨，可以明确要求再试一次。配置检查通过不代表电话已经接通。

## 4. 以后在其他任务中启用

完成首次安装后，在需要电话汇报的 Codex 任务里发送：

> 使用 $codex-call-the-boss，检查已保存的配置，仅为当前任务启用完成电话汇报和电话指令。缺少配置时请引导我补齐，不要改变其他任务的设置。

每个任务单独启用。说“这次不要打电话”只跳过当前一次；说“关闭当前任务电话汇报”则停止该任务后续的自动汇报。更新或重新配置前，请先结束通话并等待待处理任务完成。

## 声音、费用与使用提醒

- 首次使用由你选择配音方式；识别和回答使用已登录的 Codex 及其账户额度，电话使用你自己的手机套餐。
- 豆包配音需要你自己的凭据，并可能产生额外费用；合成文本会发送至火山引擎。模型和音色由你确认后保存，已有用户的选择不会自动更改。
- 每通电话最多提交一条执行指令，接收窗口默认最长 8 分钟，包含排队与通话准备时间。提交后如需取消，请回到原任务处理。
- 指令送达不代表已经开始执行。如果电话提示执行状态尚未确认，请在原任务查看进度。
- 电话不会增加原任务的权限。接听者身份不会被认证，不要用共享或转接号码处理无人值守的敏感任务。
- 记录保存在你自己的电脑上，需自行清理；分享问题时不要附带私人配置或完整通话记录。
- 本项目处于实验阶段，先在自己的设备上试用，再决定是否适合日常工作。

需要查看安装细节时，参阅[配置步骤](setup.md)和[电话指令通道说明](synchronous-stop.md)。这些技术步骤可以交给 Codex 阅读并执行，你只需完成需要本人操作或确认的部分。
