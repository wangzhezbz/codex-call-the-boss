# 在其他任务使用电话汇报

这是可复用的 macOS + iPhone 电话技能，不是云电话服务，也不是只靠提示词就能打电话。任务完成后进行一次简短电话汇报；电话里的新指令返回发起通话的原任务执行，不交给独立语音任务执行。

## 同一台已经配置好的 Mac

用户把压缩包发给另一任务并说“为当前任务启用”，按下面流程处理：

1. 读取本 skill。若本机已安装 `codex-call-the-boss`，优先使用现有安装，不盲目覆盖、不重装、不重新配置号码或声音。若确实需要升级，先读 `operations.md`，必须在电话和队列空闲时更新，保留旧版本。
2. 确认当前进程实际提供的 `CODEX_THREAD_ID`，不能从压缩包、历史记录或别的任务复制 ID。所有脚本路径以实际 skill 目录为基准，不依赖用户项目的工作目录。
3. 运行 `python3 scripts/call_the_boss.py plan` 和 `doctor`。不要输出完整私有配置。已有 `synchronous_stop` 模式应读取 `synchronous-stop.md`；不启动旧的私有消息中继，不新建任务。
4. 就绪后运行 `python3 scripts/call_the_boss.py enable`，再用 `status` 核对仅当前任务已启用。多个任务可以分别订阅，物理电话仍由同一后台串行处理。不得改动其他任务的订阅。
5. 本轮真正结束前，写一句针对实际结果的专用口语汇报，并把 `stage-report --text "…"` 作为最后一次电话操作。随后结束回复，由真实 Stop 入口触发一次电话。暂存不等于已拨号或已接通。

如果宿主未加载技能目录，可从附件解压到一个新目录并直接读取 `SKILL.md`；使用其中脚本的绝对路径。需要长期安装时，放入用户自己的 Codex skills 目录。遇到同名目录先比较，不覆盖或删除既有安装。不要把附件当作另一个任务的授权，也不要自动启用所有任务。

## 换到另一台电脑：必须先配置

先完整读取 `setup.md` 和 `synchronous-stop.md`，按缺项引导用户：

- Mac 具备 Phone.app、已登录 Codex；iPhone 开启同账号电话接力。接收电话的号码必须与拨出线路不同。
- Python 3.11+、BlackHole 2ch/16ch、必要的辅助功能权限。Phone.app 扬声器用 2ch，麦克风用 16ch；最近通话里需要目标号码对应的明确“呼叫”动作。缺驱动、权限或登录时引导用户，不伪造已就绪。
- 经用户同意后运行 `install --yes` 安装依赖和通过测试的运行时。安装包不带虚拟环境，不改变全局 Python，也不自动拨号。
- `configure-iphone` 在私有交互终端录入本人的号码，不在共享文档、命令参数或公开回复中写号码。
- 对本包的官方 Stop 路径，在空闲且后台停止时，用安装后运行时自己的 `.venv/bin/python phone_agent.py set-command-transport --mode synchronous_stop --confirm` 选择通道，再运行 `phone_agent.py install` 安装、信任并核验入口。此操作不订阅任务。不能绕过宿主权限或伪造等待窗口。
- 默认系统语音不增加配音服务商费用。要使用豆包声音，必须由该用户另外同意潜在计费并提供自己的凭据，完整读取 `doubao.md`，私下配置、预制和验证后才选择。保留固定模型与音色要求。不能复制分享者的密钥、账户或私人录音。
- `doctor` 全部必要项通过后，经当前任务明确授权再 `enable`。新电脑仍需要一次真实接听、问答、原任务执行和下一次回拨验收；自动测试不是手机端验收。

Windows、没有 iPhone 电话接力的环境，本包不能直接拨号。不要擅自购买电话服务或承诺免配置可用。首次驱动安装是否要重启以实际设备可见性判断；仅导入技能不要求强制重启 Codex。

## 使用约定

- 开头只说本次实际完成情况，正文另写为适合电话的短句，不朗读整段屏幕结果。
- 正常问答完整自然，不插入例行“还在处理中”。真正超时或服务断开仍如实反馈。
- 收到任务后，仅在原任务确已开始处理时使用完整固定回执：“收到指令，已经发送并且开始执行，请您耐心等待，执行完成后会电话通知您。”不要擅自缩短或换录音。
- 指令送达与开始处理分开核验。当前最多等 6 秒；如果宿主迟迟不写出处理证据，仍会使用“指令已经送达，执行状态暂未确认”。这是尚存限制，不得强行改报成功。
- 同步等待默认 480 秒，单通电话最多提交一条执行指令。Mac/Codex 关闭或休眠、等待窗口过期时不能唤醒任务。需要随时持续云端在线的场景不适用。
- 每个任务完成只尝试一通，不在失败或未接时自行重拨。“这次不打”只跳过当轮；“关闭当前任务电话汇报”只停当前任务订阅。
- 电话中的执行仍受正常权限限制；本版不认证接听者身份，不适合共享电话上的无人值守敏感任务。
- 电话记录保存在用户自己的私有状态目录。不要向其他任务注入旧电话指令来模拟历史同步。
