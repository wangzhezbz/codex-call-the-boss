# 第一次使用 Call the Boss

让 Codex 在工作完成后打电话简短汇报。你可以在电话里提问、交代下一步工作，指令会回到原来的 Codex 任务执行。

## 1. 准备设备

- 一台带有 Phone.app 的 Mac，已登录 Codex 桌面端。
- 一部与 Mac 使用同一 Apple 账户、已开启“在其他设备上通话”的 iPhone，手机线路可以正常拨出电话。
- 一个能接听电话的号码，不能与拨出线路相同。请在 Codex 引导的私有交互终端中填写，不要写入公开文件。
- Mac 和 Codex 在使用期间保持运行，不要休眠。

还需要 Python 3.11+、BlackHole 2ch/16ch 和辅助功能权限。没有安装也不用猜着配置，先让 Codex 检查，再按提示补齐。Phone.app 最近通话中需要有接听号码和可用的“呼叫”按钮；若没有，Codex 会提示你手动建立这条记录。

目前支持 macOS + iPhone，不支持 Windows、Linux 或没有 iPhone 电话接力的环境。

## 2. 让 Codex 引导安装

解压下载的 Skill，将其中的 `codex-call-the-boss` 文件夹交给 Codex，发送：

> 我是第一次使用 Call the Boss。请读取这个文件夹里的 SKILL.md，先检查我的设备和环境，再引导我完成安装、电话接力、接听号码、音频和权限配置。不要假设我已有任何电话配置。安装组件、修改权限或启用收费服务前先征求我的同意。配置完成后，仅为当前任务启用电话汇报，不要直接拨号，等我确认后再试打。

安装、配置和启用是不同步骤。下载或解压不会自动拨号；如果你要求先不拨号，本次配置结束也不应触发电话。启用后，之后的任务完成会自动汇报。

如果 Codex 无法读取附件，告诉它解压后的文件夹完整路径，让它从其中的 `SKILL.md` 开始。已有同名安装时，先检查，不直接覆盖。不要从分享者那里复制号码、密钥、账户登录或通话记录。

## 3. 检查配置并试打一通

配置完成后，让 Codex 检查运行状态。确认可以测试后，说：

> 打给我测试一次。

接听并说“喂”，检查以下几项：

1. 能听清简短汇报。
2. 能正常提问和听到回答。
3. 下达一条简单任务后，原任务窗口收到并执行了指令。
4. 该任务完成后，收到下一次电话汇报。

每次只拨打一次。未接到或失败时不会自动重拨，可以明确要求再试一次。配置检查通过不代表电话已经接通。

## 4. 以后在其他任务中启用

完成首次安装后，在需要电话汇报的 Codex 任务里发送：

> 使用 $codex-call-the-boss，检查已保存的配置，仅为当前任务启用完成电话汇报和电话指令。缺少配置时请引导我补齐，不要改变其他任务的设置。

每个任务单独启用。说“这次不要打电话”只跳过当前一次；说“关闭当前任务电话汇报”则停止该任务后续的自动汇报。更新或重新配置前，请先结束通话并等待待处理任务完成。

## 声音、费用与使用提醒

- 默认使用系统语音；识别和回答使用已登录的 Codex 及其账户额度，电话使用你自己的手机套餐。
- 可选豆包配音需要你自己的凭据，并可能产生额外费用。需要时请让 Codex 按[豆包配置说明](doubao.md)引导，使用 Doubao-语音合成-2.0。
- 每通电话最多提交一条执行指令，接收窗口默认最长 8 分钟，包含排队与通话准备时间。提交后如需取消，请回到原任务处理。
- 指令送达不代表已经开始执行。如果电话提示执行状态尚未确认，请在原任务查看进度。
- 电话不会增加原任务的权限。接听者身份不会被认证，不要用共享或转接号码处理无人值守的敏感任务。
- 记录保存在你自己的电脑上，需自行清理；分享问题时不要附带私人配置或完整通话记录。
- 本项目处于实验阶段，先在自己的设备上试用，再决定是否适合日常工作。

需要查看安装细节时，参阅[配置步骤](setup.md)和[电话指令通道说明](synchronous-stop.md)。这些技术步骤可以交给 Codex 阅读并执行，你只需完成需要本人操作或确认的部分。
