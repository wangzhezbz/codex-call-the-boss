# Call the Boss

Codex звонит, когда работа закончена: кратко сообщает результат, отвечает на вопросы и принимает следующую задачу. Команда возвращается в **исходную задачу Codex**, а не отдельному голосовому исполнителю.

**Экспериментальный проект · macOS + iPhone · Включение отдельно для каждой задачи**

| macOS + iPhone | Windows | Linux |
| :-- | :-- | :-- |
| Локальный навык, нужна настройка | Не поддерживается | Не поддерживается |

Это локальный телефонный мост, не облачная служба и не мобильное приложение. Пять языков относятся к публичной документации, **не к проверенной поддержке разговоров на пяти языках**. Внутренняя техническая документация преимущественно на английском.

## Как это работает

1. Подключённая задача завершает работу и готовит краткий текст для звонка.
2. Mac делает одну попытку звонка через iPhone. После ответа и приветствия воспроизводится отчёт.
3. Можно задавать вопросы. Распознавание и ответы используют текущую учётную запись Codex, озвучивание — выбранный голосовой движок.
4. Одна новая команда передаётся дословно в исходную задачу. Она выполняется в рамках обычных разрешений Codex.
5. Завершение этой работы может вызвать следующий звонок.

Соединение, доставка команды, начало выполнения и завершение — разные состояния. Голосовой контекст сам задачи не исполняет.

## Начало работы

### Другая задача на уже настроенном Mac

Прикрепите [ZIP навыка](../dist/codex-call-the-boss.skill.zip) к нужной задаче и напишите:

> Прочитай SKILL.md из вложения. Используй существующие настройки телефона на этом Mac и включи отчёты о завершении и телефонные команды только для текущей задачи. Сначала проверь готовность, помоги настроить недостающее и не меняй подписки других задач.

Если навык установлен, используйте `$codex-call-the-boss` с этим запросом. Сам импорт ничего не включает. Нельзя перезапускать или перезаписывать общий сервис, пока идёт звонок или есть очередь.

### Новый Mac

Нужны Phone.app, приложение Codex с выполненным входом, Python 3.11+, телефонная связь через iPhone, номер получателя, отличный от исходящей линии, BlackHole 2ch/16ch и разрешения специальных возможностей. В недавних вызовах Phone.app должна быть запись получателя с доступным действием вызова. Mac и Codex должны работать и не находиться в режиме сна.

Распакуйте архив и попросите Codex прочитать `SKILL.md` и провести настройку. Установка драйверов и зависимостей, изменение разрешений и подключение потенциально платного синтеза речи требуют согласия пользователя. Установщик проверяет новую версию перед активацией и фиксирует версии основных зависимостей.

Проверка без изменений из распакованной папки `codex-call-the-boss`:

```bash
python3 scripts/call_the_boss.py plan
```

После установки `doctor` проверяет локальную готовность; `enable` подключает только текущую задачу после настройки и явного запроса. См. [настройку](../skills/codex-call-the-boss/references/setup.md) и [синхронный Stop](../skills/codex-call-the-boss/references/synchronous-stop.md). Не обходите запреты частного интерфейса и не запускайте второй процесс записи исходной задачи.

## Голос и расходы

Распознавание и ответы используют текущий вход Codex и его лимиты, без отдельного OpenAI API Key. Звонки идут через ваш мобильный тариф; бесплатность и неограниченное использование не обещаются. По умолчанию используется системный голос. Необязательный Doubao TTS требует собственных ключей и согласия на возможные расходы; модель закреплена как **Doubao speech synthesis 2.0 / `seed-tts-2.0`**. См. [инструкцию Doubao](../skills/codex-call-the-boss/references/doubao.md).

В архиве нет номеров телефонов, ключей, сеансов входа, голосового кэша или записей звонков.

## Ограничения

- **Не готово для промышленной эксплуатации.** Автотесты не заменяют проверку реального звонка или новой машины.
- Синхронный Stop по умолчанию ждёт 480 секунд. Он не будит закрытый или спящий Codex. Один звонок передаёт одну команду; немедленная отмена уже переданной команды через это одноразовое окно недоступна.
- Подтверждение «выполнение началось» требует доказательства обработки в исходной задаче за 6 секунд. При запоздалых записях может прозвучать только подтверждение доставки, даже если задача позже начнётся.
- Одна попытка звонка на завершение, без автоматического повтора после ошибки или неопределённого результата. Обычная реплика «ещё обрабатывается» отключена; реальные ошибки сообщаются.
- Звук, перебивания, сеть, квоты и совместимость версии Codex требуют проверки на реальных звонках.
- Личность отвечающего не проверяется. Не используйте общие или переадресованные номера для чувствительных задач без присмотра.
- Записи хранятся локально до удаления владельцем; автоматический срок хранения не установлен. Не публикуйте приватный каталог состояния.
- Навык не добавляет посторонние инструменты, например полноэкранное конфетти.
