# Call the Boss

Codex の作業が終わったら、電話で短く報告。質問したり、次の作業を声で指示したりできます。指示は**元の Codex タスク**に戻って実行されます。

**実験段階 · macOS + iPhone · タスクごとに明示的に有効化**

| macOS + iPhone | Windows | Linux |
| :-- | :-- | :-- |
| ローカルスキル・初期設定が必要 | 非対応 | 非対応 |

Mac と iPhone の通話機能を使うので、スマートフォンに追加のアプリは不要です。初回の設定は Codex が案内します。

## 動作の流れ

1. 有効化したタスクが作業を終え、電話専用の短い報告文を準備します。
2. Mac が iPhone の通話連係を使って1回発信。応答して挨拶すると報告を再生します。
3. 通常の質問ができます。音声認識と回答はログイン済み Codex、読み上げは選択した音声エンジンが担当します。
4. 次の指示を1件伝えると、その原文が元のタスクに戻り、通常の権限の範囲で実行されます。
5. その作業が完了すると、次の報告電話につながります。

電話で依頼した作業は元の Codex タスクで進みます。進捗や結果は、いつでもタスクの画面で確認できます。

## 電話での使い方

1. **電話に出て挨拶し**、短い完了報告を聞きます。
2. **普段どおりに質問できます**。「何が完了した？」「まだ問題はある？」「なぜそう変更した？」「この2案の違いは？」など、結果や理由、次の方針を相談できます。「もう一度」「もっと簡単に説明して」と頼んでも構いません。相談だけでプロジェクトの変更を依頼したことにはなりません。
3. **作業を実行してほしいときは、はっきり伝えてください。**

   > 次のタスクは、XXXXX です。

   中国語で話す場合は **「下一步的任务是：XXXXX。」** と伝えます。例：「次のタスクは、トップページの全リンクを確認し、切れたリンクを修正して、変更点を報告することです」。作業内容、範囲、完了条件を具体的に伝えましょう。
4. **指示の到達を確認する応答を聞きます。** 到達が確認できたら電話を切り、完了後の報告電話を待てます。実行状況が未確認と案内された場合は元のタスクで確認してください。到達と実行開始は別です。

実行指示は1通話につき1件です。送信後の追加、変更、取り消しは元の Codex タスクで行ってください。質問だけして、新しい作業を頼まずに電話を切っても構いません。

初回の試し通話前に、Codex がこの使い方を説明してから発信の確認を求めます。

## 使い始める

### 1. 機器を準備する

Phone.app のある Mac、ログイン済みの Codex デスクトップアプリ、通話連係を有効にした iPhone が必要です。着信先には、発信回線とは別の電話番号をご用意ください。

Python 3.11+、BlackHole 2ch/16ch、アクセシビリティ権限も必要です。Codex が確認し、不足する設定を案内します。Phone.app の履歴に着信先の番号と利用可能な発信ボタンが必要です。使用中は Mac と Codex を起動したまま、スリープさせないでください。

### 2. ダウンロードして Codex と設定する

[スキルの ZIP](../dist/codex-call-the-boss.skill.zip) をダウンロードして展開し、Codex が展開後の `codex-call-the-boss` フォルダーを読める状態にして、次のように依頼してください。

> Call the Boss を初めて使います。このフォルダーの SKILL.md を読み、機器と環境を確認して、インストール、iPhone の通話連係、着信番号、音声、権限の設定を案内してください。電話の設定が済んでいると仮定しないでください。ソフトウェアのインストール、権限変更、有料サービスの利用前には同意を求めてください。設定後は現在のタスクだけで電話報告を有効にし、試し通話は私が確認してから行ってください。

Codex の案内に沿って設定してください。コード内のパラメーターを自分で編集する必要はありません。詳しくは[設定手順](../skills/codex-call-the-boss/references/setup.md)をご覧ください。

### 3. 試しに電話をかける

設定の確認が完了したら、Codex に「テストで1回電話をかけて」と依頼します。電話に出て挨拶し、報告が聞こえるか、質問できるかを確認して、簡単な作業を指示してください。元のタスクに戻り、指示が届いて実行されたかを確認します。

### 別のタスクでも使うには

初回のインストール後、電話報告を使いたい Codex タスクで次のように依頼してください。

> $codex-call-the-boss を使って保存済みの設定を確認し、現在のタスクだけで完了報告電話と電話からの指示を有効にしてください。不足する設定を案内し、他のタスクの設定は変更しないでください。

タスクごとに有効化が必要です。更新や再設定は、通話と待機中の処理が終わってから行ってください。

## 音声と料金

初回設定では、Codex が**システム音声と Doubao 音声のどちらを使うか**を尋ねます。勝手に選択することはありません。

- **システム音声**：Mac にインストール済みの声を選択します。音声合成サービスへの追加料金はありません。
- **Doubao 音声**：モデルと声を選択します。読み上げるテキストが Volcengine に送信され、利用料金が発生する場合があります。
- 認識と回答はログイン済み Codex の利用枠、通話は携帯電話の契約を使用します。この経路に OpenAI API Key は不要です。

### Doubao を選んだ場合

**3. 音声モデルを自分で選ぶ**こともできます。モデル名や ID を Codex に伝え、有効化前に互換性を確認してください。

1. [Volcengine コンソール](https://console.volcengine.com/ark/region:cn-beijing/overview)で登録またはログインします。
2. [TTS モデルの有効化](https://console.volcengine.com/ark/region:cn-beijing/openManagement?advancedActiveKey=model&tab=TTS)を開きます。既製の音声には **Doubao speech synthesis 2.0**（`seed-tts-2.0`）をおすすめします。利用権限のある複製音声を既にお持ちなら **Doubao voice cloning 2.0**（`seed-icl-2.0`）も選べます。料金を確認してご自身で選択してください。音声の複製サービス自体はスキルに含まれません。
3. [音声ライブラリ](https://console.volcengine.com/speech/new/voices?projectName=default)でモデルを絞り込み、試聴して正確な音声 ID をコピーします。標準 2.0 では 甜美小源 2.0、Vivi 2.0、云舟 2.0 から試せます。最後はご自身で選んでください。
4. [API Key 管理](https://console.volcengine.com/speech/new/setting/apikeys?projectName=default)で音声サービスのキーを作成します。Codex の案内に従い、非公開ターミナルの非表示入力で登録してください。チャットやリポジトリに貼り付けないでください。
5. モデル、音声、料金に同意すると、Codex が選択を保存し、合成を確認して試聴用音声を提示します。確認後に有効化し、この段階では発信しません。

現在の接続方式は上記2種類の 2.0 モデルに対応しています。他のモデルは有効化前に互換性確認が必要です。ID と詳細は [Doubao 設定](../skills/codex-call-the-boss/references/doubao.md)をご覧ください。既存の設定は維持し、キー、番号、ログイン情報、録音は配布物に含めません。

## 現在の制限

- **実験段階のため、電話通知が不可欠な重要業務には向いていません。** まずはご自身の環境でお試しください。
- Mac と Codex を起動したまま、スリープさせずに使用してください。電話から指示を受け付ける時間は既定で最大8分、実行指示は1通話につき1件です。送信済みの指示を取り消す場合は元のタスクに戻ってください。
- 指示の到達と実行開始は異なります。電話で実行状況を確認できなかった場合は、元のタスクで進捗をご確認ください。
- 完了ごとに発信は1回で、自動再発信はありません。不在着信や発信失敗の場合は、Codex に再試行を依頼できます。
- 通話品質はネットワーク、機器、Codex のバージョン、アカウントの利用枠に左右されます。ドキュメントは5言語で提供しています。会話に使う言語は、事前に試し通話でご確認ください。
- 着信者の本人確認はありません。共有・転送番号で機密性の高い作業を無人実行しないでください。
- 記録は所有者が削除するまでローカルに残り、自動保存期限はありません。プライベートな状態ディレクトリを公開しないでください。
- 電話からの指示には元のタスクのツールと権限を使います。追加の許可が必要な操作には、引き続き利用者の確認が必要です。
