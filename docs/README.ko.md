# Call the Boss

Codex가 작업을 끝내면 전화로 짧게 보고합니다. 질문하거나 다음 작업을 말로 지시할 수 있으며, 명령은 별도의 음성 실행자가 아니라 **원래 Codex 작업**으로 돌아가 실행됩니다.

**실험 단계 · macOS + iPhone · 작업별 명시적 활성화**

| macOS + iPhone | Windows | Linux |
| :-- | :-- | :-- |
| 로컬 스킬, 초기 설정 필요 | 지원하지 않음 | 지원하지 않음 |

클라우드 전화 서비스나 별도 모바일 앱이 아닙니다. 5개 언어 지원은 공개 문서에 관한 것으로, **5개 언어 통화가 검증되었다는 뜻은 아닙니다**. 내부 유지보수 문서는 주로 영어입니다.

## 작동 방식

1. 활성화된 작업이 완료되면 전화에 맞는 짧은 보고문을 준비합니다.
2. Mac이 iPhone 통화 연계를 통해 한 번 발신합니다. 전화를 받고 인사하면 보고를 재생합니다.
3. 일반적인 질문을 할 수 있습니다. 인식과 답변은 로그인된 Codex가, 읽어주는 음성은 선택한 엔진이 담당합니다.
4. 다음 작업 하나를 지시하면 원문이 원래 작업으로 전달되어 통상적인 권한 범위에서 실행됩니다.
5. 그 작업이 끝나면 다음 보고 전화를 할 수 있습니다.

음성 컨텍스트는 질문에 답할 뿐 별도의 작업 실행자가 아닙니다. 전화 연결, 명령 전달, 실행 시작, 완료는 각각 확인합니다.

## 시작하기

### 이미 설정한 Mac의 다른 작업

대상 작업에 [스킬 ZIP](../dist/codex-call-the-boss.skill.zip)을 첨부하고 다음과 같이 요청하세요.

> 첨부한 SKILL.md를 읽어 주세요. 이 Mac의 기존 전화 설정을 재사용하고 현재 작업에만 완료 보고 전화와 전화 명령 실행을 활성화해 주세요. 먼저 준비 상태를 확인하고 부족한 설정을 안내해 주세요. 다른 작업의 구독은 바꾸지 마세요.

이미 설치했다면 `$codex-call-the-boss`와 위 요청을 사용할 수 있습니다. 첨부하거나 가져오는 것만으로 전화가 활성화되지는 않습니다. 통화 중이거나 대기 작업이 있으면 공용 런타임을 덮어쓰거나 다시 시작하지 마세요.

### 새 Mac

Phone.app, 로그인된 Codex 데스크톱, Python 3.11+, iPhone 통화 연계, 발신 회선과 다른 수신 번호, BlackHole 2ch/16ch, 필요한 손쉬운 사용 권한이 필요합니다. Phone.app 최근 통화에는 대상 번호와 식별 가능한 발신 동작이 있어야 합니다. Mac과 Codex를 실행 상태로 유지하고 잠자기 상태로 두지 마세요.

ZIP을 풀고 Codex가 `SKILL.md`를 읽어 설정을 안내하도록 요청하세요. 드라이버·의존성 설치, 권한 변경, 비용이 발생할 수 있는 음성 서비스 선택에는 사용자의 동의가 필요합니다. 설치 프로그램은 주요 의존성 버전을 고정하고 새 버전의 테스트를 통과한 뒤 전환합니다.

압축을 푼 `codex-call-the-boss` 폴더에서 변경 없이 확인할 수 있습니다.

```bash
python3 scripts/call_the_boss.py plan
```

설치 후 `doctor`로 로컬 준비 상태를 확인하고, 설정 완료 및 명시적 요청 뒤에만 `enable`로 현재 작업을 활성화합니다. [설정 안내](../skills/codex-call-the-boss/references/setup.md)와 [동기 Stop 경로](../skills/codex-call-the-boss/references/synchronous-stop.md)를 따르세요. 거부된 비공개 경로를 우회하거나 원래 작업에 두 번째 쓰기 프로세스를 만들지 마세요.

## 음성과 비용

인식과 답변은 현재 Codex 로그인 및 사용 한도를 이용하며, 이 경로에는 OpenAI API Key가 필요하지 않습니다. 통화는 본인의 휴대전화 요금제를 사용하므로 무료·무제한을 보장하지 않습니다. 기본값은 시스템 음성입니다. 선택 사항인 Doubao TTS는 본인 인증 정보와 비용 동의가 필요하며 **Doubao speech synthesis 2.0 / `seed-tts-2.0`** 모델을 고정 사용합니다. [음성 설정](../skills/codex-call-the-boss/references/doubao.md)을 참고하세요.

배포 파일에는 전화번호, 키, 로그인 세션, 음성 캐시, 통화 녹음이 포함되지 않습니다.

## 현재 제한

- **아직 프로덕션용 서비스가 아닙니다.** 자동 테스트는 실제 통화나 새 기기 검증을 대신하지 않습니다.
- 동기 Stop의 기본 대기 시간은 480초입니다. 종료되거나 잠든 Codex를 깨우지 못합니다. 한 통화에 실행 명령 하나만 전달하며, 이미 전달한 명령을 이 일회성 창으로 즉시 취소할 수는 없습니다.
- 완전한 “실행 시작” 응답에는 6초 안에 원래 작업의 처리 증거가 필요합니다. 기록이 늦으면 나중에 실행되더라도 전달만 확인한 응답이 나올 수 있습니다.
- 완료마다 한 번만 발신합니다. 실패하거나 결과가 불확실하면 자동으로 재발신하지 않습니다. 일상적인 “처리 중” 안내는 꺼져 있지만 실제 오류는 알립니다.
- 음질, 끼어들기, 네트워크, 계정 한도, 호스트 버전 호환성은 실제 통화로 검증해야 합니다.
- 수신자의 신원을 인증하지 않습니다. 공용·착신 전환 번호로 민감한 작업을 무인 실행하지 마세요.
- 기록은 소유자가 삭제할 때까지 로컬에 보관되며 자동 보존 기간은 설정되지 않습니다. 비공개 상태 폴더를 업로드하지 마세요.
- 전체 화면 축하 효과 등 별도 작업 도구는 이 스킬에 포함되지 않습니다.
